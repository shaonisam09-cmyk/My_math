# 共同设定（主 agent 统一，供 A、B、C 使用）

## 研究方向（用户已确定）
有限窗口是近期风险的统计指标和运行考核对象；更新公式不必显式包含窗口均值。
用户的原始动机：全历史累计违约率反馈随时间推移对新工况越来越不敏感；工业运行更关心近期表现。
候选更新公式不以“有没有窗口”取舍，也不以“更复杂即更先进”取舍。

## 统一符号（每个受调约束 i 单独一套；下文省略 i）
- 名义界 $G s\le g$；绝对物理/安全界另行硬约束，不参与风险反馈。
- 违约指示 $O_t=\mathbf 1\{G s_t>g+\varepsilon\}$，其中 $\varepsilon\ge0$ 为事先声明的测量/求解容差（默认 0）。
- 边界调整量 $r=-h$（与约束同单位：储能 MWh，温度 K）；$r>0$ 放松，$r<0$ 收紧。允许区间 $[\underline r,\overline r]$。
- MPC 在时刻 t 对预测步 $\ell=1..H$ 统一施加 $G\hat s_{t+\ell|t}\le g+r_t$；当前实测状态不受新界约束。

## 信息时序（按稿件方程重建，不添加过程噪声）
1. 时刻 t：测得实际状态 $s_t$ 及当期外生量（稿件：电价、可再生出力、交互负荷、当期到达），计算 $O_t$（它是 $t-1$ 时刻决策的结果）。
2. 更新 $r_t=\Pi[r_{t-1}+\kappa(\alpha-O_t)]$（等价于用户写法 $r_{t+1}=\Pi[r_t+\kappa(\alpha-O_{t+1})]$，其中 $r_t$ 用于产生下一次观测 $O_{t+1}$ 的决策）。
3. 用 $r_t$、实测当期量和 H 步预测求解 MPC；执行第一步（稿件有供电侧“可再生优先”修正，只改 $p^r,p^{gd}$，不改储能指令）。
4. 实际对象演化到 $s_{t+1}$。储能：按稿件递推，下一状态由已执行指令确定（决策后确定事件）。温度：按控制模型递推亦确定，实际违约只来自控制模型与实际对象的失配（实际对象在稿件中未定义）。

## 必须区分的量
单时刻条件违约概率；有限窗口经验违约率 $Y^w_t$；长期累计经验违约率；一段时间内平均条件违约概率；多约束联合违约事件。

## 候选
- EV（主候选）：投影逐事件 $r_t=\Pi_{[\underline r,\overline r]}[r_{t-1}+\kappa(\alpha-O_t)]$。
- W0（主要对照）：当前窗口均值投影加法 $r_t=\Pi[r_{t-1}+\kappa_t(\alpha-Y^w_t)]$，$\kappa_t=\kappa n_t/w$（等价于 α 预填 + 固定增益）。
- G（对照）：Ghosh 原乘法更新 $h_t=h_{t-1}[1+(\alpha-Y_t+\tfrac{2Y_t-1}{2(t+1)})/\gamma]$，$Y_t$ 为全历史累计平均，$h<0$。
- 至多一个简洁替代（只有发现明确、重要、无法靠参数处理的缺陷时才加入），例如抗饱和或滤波。

## 已被更正、不得再用的旧说法（见 merged_adaptive_update_math_study 报告与第二轮报告文首更正）
- “储能下限必须 ≤ −κ(1−α)” 只是阈值模型下覆盖整个不变区间的充分条件，不是必要条件（反例：下限 −0.8κ 仍精确）。
- “零下界导致 50% 违约”仅在 $\underline r=\theta$、$r_0=\theta$、$\overline r\ge\theta+\kappa\alpha$、$0<\alpha\le1/2$ 时成立；α=0.7 时为 3/4。
- ρ=10 只是示例，不是已验证默认值。

- 任何玩具结果都不是数据中心实验证据；旧 case study 为旧版实现。
