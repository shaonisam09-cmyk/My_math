# 主 agent 笔记：窗口预算比例–积分更新（WB-PI）

状态：主 agent 的构造与初步推导，**待第二阶段证明者与红队核查**。玩具数值仅供参考，不代表数据中心实验。

## 1. 机制定义

记窗口计数为 $K_t=\sum_{j=t-n_t+1}^{t}O_j$，$Y^w_t=K_t/n_t$，其中 $n_t=\min(t,w)$。

**窗口预算误差**（两种版本）：

- 基本版：$e_t=\alpha-Y^w_t$，即“窗口内剩余违约预算 / 窗口长度”。
- 中点版：$\tilde e_t=\alpha-Y^w_t+\dfrac{2O_{t-w+1}-1}{2w}=\dfrac{(w\alpha-\tfrac12)-S_t}{w}$。其中 $S_t=K_t-O_{t-w+1}$ 为下一步仍会留在窗口内的计数。它就是 Ghosh 修正项与稿件退出位修正项的窗口版，仅用于比例通道。

**两个状态**：

$$
b_t=\Pi_{[l_b,u_b]}\big[b_{t-1}+\kappa_I\tfrac{n_t}{w}\,e_t\big],\qquad
r_t=\Pi_{[l,u]}\big[b_t+\kappa_P\,\tilde e_t\big],\qquad b_0=r_0=0.
$$

- $b_t$：慢速积分基准，只积分基本误差 $e_t$，用于校准；
- $\kappa_P\tilde e_t$：比例部分，直接由窗口预算决定。

记 $\Delta_P=\kappa_P/w$，含义是“窗口内每多一次（或少一次）违约，边界收紧（或放松）$\Delta_P$”，单位与 $r$ 相同。等价写法为

$$r_t=\Pi\big[b_t+\Delta_P\,(\text{剩余违约预算})\big],\qquad \text{剩余预算}=(w\alpha-\tfrac12)-S_t .$$

MPC 在时刻 $t$ 对 $\ell=1..H$ 施加 $G\hat s_{t+\ell|t}\le g+r_t$。

## 2. 主 agent 的初步结论

**(A) 校准恒等式由积分状态承载（满窗阶段，$b$ 未截断时）。**

$$\sum_{t=a+1}^{c}(Y^w_t-\alpha)=\frac{b_a-b_c+\sum q^b_t}{\kappa_I}.$$

比例项不参与积分，因此恒等式**没有比例项的代价**。这与速度式 PI（$r_t=r_{t-1}+\kappa_Ie_t+\kappa_P(e_t-e_{t-1})$）不同：速度式的恒等式多出 $\kappa_P(e_c-e_a)/\kappa_I$。

**(B) 阈值响应下精确实现理想窗口策略。**

- 设在某时段内 $O_{t+1}=\mathbf 1\{r_t>\theta\}$，$l\le\theta<u$，且 $b_t=\theta$。则 $O_{t+1}=\mathbf 1\{\tilde e_t>0\}=\mathbf 1\{S_t<w\alpha-\tfrac12\}$，这正是方案文件第 8 节的理想窗口事件策略（取 $k$ 为最接近 $w\alpha$ 的整数）。因此该定理（至多 $\max(k,w-k)$ 步到达，随后计数保持为 $k$，$|Y-\alpha|=\mathrm{dist}(\alpha,\{j/w\})\le\tfrac1{2w}$）**直接适用于实际更新**。
- 若 $b_t\ne\theta$，阈值平移 $(\theta-b_t)/\Delta_P$ 个计数单位，窗口计数停在平移后的整数附近，而 $b$ 在积分作用下被推回 $\theta$。
- 储能取 $l=\theta=0$ 时，$b$ 在 0 处被截断，因此不需要负下界。

**(C) 线性化稳定性（光滑静态响应，斜率 $F'$）。**

- 仅比例通道：特征多项式为 $z^w+c\sum_{j=0}^{w-1}z^j$，其中 $c=\kappa_PF'/w=\Delta_PF'$。乘以 $z-1$ 得 $z^{w+1}-(1-c)z^w-c$。当 $0<c<1$ 时，在单位圆上 $|z-(1-c)|\ge c$，等号仅在 $z=1$ 处成立，而 $z=1$ 是乘出来的伪根，所以全部根严格位于单位圆内；当 $c>1$ 时，根的模之积为 $c>1$，必有根在圆外。**结论：稳定当且仅当 $\Delta_PF'<1$，与 w 无关。**（数值核对：w=2..200 时临界值都等于 w。）
- 加入积分：临界 $\kappa_IF'w$ 约为 8–15（w=96，$g_P$ 取 1–50）。积分通道必须慢，但快速反应由比例通道承担。

**(D) 玩具数值（主 agent）**：$\alpha=0.1$，$w=2880$，$\kappa_I=0.0174$。

2. (B) 的严格证明，包括 $b\ne\theta$ 时的收敛性，以及 $l=\theta$ 截断下的行为。
