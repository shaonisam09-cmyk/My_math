# P2：窗口预算 PI（盒形 WB-PI）的证明结果汇编

**说明**：证明者 P2 三次因 API 额度中断，没有写出自己的文档。本文件由主 agent 根据 `P2_scripts/` 中已保存的运行输出汇编。结论以输出文件为准，并标明证据类型；凡是 P2 没有留下完整证明文本的，一律只标为“数值或穷举证据”。结合 R2、R3 的审查结果，盒形 WB-PI 已被否决为主方法，本文件只作记录。

## 1. 校准恒等式（`p2_prop1_5_output.txt`）

- (1a)(1b)(1c)：在 300 个随机例中精确核对通过，包括 $b$ 与 $r$ 两个投影同时截断、启动段、任意 0/1 序列。恒等式 $\sum(Y^w_t-\alpha)=(b_a-b_c+\sum q^b)/\kappa_I$ 精确成立。
- (1d)：速度式 PI 的恒等式同样在 300 例中精确通过。与位置式相比，它多出 $\kappa_P(e_c-e_a)/\kappa_I$ 与 $r$ 的投影残差。这是 D1 所述速度式正偏差的来源。
- (5)：平均条件概率的鞅界做了 400 次蒙特卡罗（logistic 闭环，w=48，α=0.1，G=3，N=2000）。δ=0.1 与 δ=0.05 下违反频率都是 0。

## 2. 阈值情形

- **积分开启时的规则带进入**（`p2_prop2c_output.txt`）：
  - 化简式（完整 b/r/投影 更新 = β 形式）在 40 个随机例中精确一致，每例 400 步，有理数运算。
  - 穷举全部初始窗口与多个 $\beta_0$，w=6–10，g=κ_I/Δ_P∈{0.25, 0.5, 0.6}：所有轨道都进入规则带，最晚进入时刻有限（例如 w=9、α=0.1 时为 423 步）。
  - 这是**穷举证据**，不是一般 w 的证明。
- **b ≡ θ 时**（`p2_prop2d_output.txt`）：w=3–10 穷举全部通过以下三项：
  - 每段连续违约不超过 k；
  - $K\le\max(K_0,k)$；
  - 复活后不超过 k 步回到 k。
- **积分开启且存在静默期时**（玩具，w=2880）：β 无上限时最长连续违约 524–914，β 上限取 2 时为 290，但总违约率降到 0.029–0.052。结论：预算累积与积分饱和会产生长段连续违约；限制 β 能缩短连续违约，却会浪费预算。
- **基本版加积分**（`p2_prop2b_basic_integral_output.txt`）：稳态计数在 ⌈wα⌉ 附近的 2–3 个整数之间切换，平均窗口率等于 α（误差 ≤ 1e-4）。

## 3. 线性稳定性（`p2_prop3_output.txt`）

- **仅比例通道**：基本版与中点版的临界 c 都等于 1，w=2..40、60、96、150、200 时最大偏差 4.1e-7。c=1 时根模全部为 1（边界情形）。
- **最慢模态衰减**：$1-\rho\approx2\pi^2(1-c)/(c^2w^3)$，与数值吻合，例如 w=480、c=0.5 时为 3.5e-7。盒形比例通道的阻尼因此极弱，与 R2 的回声结论一致。
- **完整 PI 的临界 $G=\kappa_IF'w$**：中点版随 c 增大升到约 19.7（w=2880）；基本版在 c 较大时迅速下降（例如 w=96、c=0.9 时为 1.93）。**中点版明显比基本版稳健。**

## 4. 随机情形（`p2_prop3_logistic_output.txt`、`p2_prop4_output.txt`）

- logistic 平均场：G 超过线性临界（w=96 时约 19.3）后出现小幅持续振荡；随机二值情形下，窗口周期附近的谱功率占比随 G 增大，从 0.11 升到 0.24。
- 端点不等式响应（$S<k$ 时 $p\ge p_+$，否则 $p\le p_-$）：各种策略下窗口计数偏差 D 的 1%–99% 分位都在 [−1, 3] 内，时间平均 $|Y-\alpha|\cdot w<1$。它支持“$O(1/w)$ 量级集中”的猜想，但**没有证明**。聚集型扰动下，w=2880 时最长连续违约升到 35。

## 5. 启动写法（`p2_startup_output.txt`）

| w, α | 按计数启动：稳态最长连续违约 | 按比率启动 |
|---|---|---|
| 96, 0.1 | 10 (=k) | 1 |
| 96, 0.25 | 24 (=k) | 1 |
| 480, 0.1 | 48 (=k) | 1 |
| 2880, 0.1 | 288 (=k) | 1 |

按计数启动会形成 k 步连续违约，并被窗口以周期 w 永久复制。**启动必须按样本数折算，或者用 α 预填。**
