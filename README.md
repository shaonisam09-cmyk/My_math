# My_math

Private research archive for a manuscript on data-center energy management with model predictive control, terminal-value approximation, and adaptive risk feedback.

## Contents

- `manuscript/`: current Energy and Buildings manuscript, compiled PDF, bibliography, LaTeX dependencies, and paper figures.
- `reference_papers/`: locally collected reference papers in PDF and Markdown form. These files are retained for private scholarly use and may remain subject to publisher copyright.
- `mathematical_studies/`: mathematical proofs, method studies, red-team reviews, counterexamples, and reports produced during the development of the adaptive risk-feedback method, including GPT- and Opus-generated studies.

## Deliberately excluded

- MATLAB, Python, and other executable source code
- datasets, model checkpoints, numerical result tables, and experiment outputs
- temporary downloads, caches, LaTeX build artifacts, backups, and isolated revision workspaces

The case-study implementation is maintained separately. Mathematical notes in this archive have different evidence levels; conditional theorems and toy-model checks should not be read as verified guarantees for the full data-center MPC unless their assumptions are explicitly validated.
